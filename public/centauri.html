Centauri

A SQL database engine written from scratch in Go, with its own query language — CeQL. Built in the open, GitHub-first.

View on GitHub ↗

The idea

Centauri is a ground-up SQL database engine — storage, parser, planner, and execution — implemented in Go rather than bolted onto an existing system. It exists to make the internals of a database legible: every layer is something you can read, run, and reason about.

CeQL

On top of the engine sits CeQL, a query language designed alongside the executor rather than retrofitted. The grammar, the planner, and the runtime evolve together, which keeps the whole stack coherent and approachable.

What it does

  • Custom storage and execution engine written in Go
  • CeQL — a purpose-built query language with its own parser and planner
  • Developed fully in the open, GitHub-first
  • Readable internals meant for learning and extension
